HARSHIT TIWARI — PORTFOLIO

To view:
1. Extract the ZIP file.
2. Open index.html in a browser.

To publish:
- Upload the whole folder to GitHub Pages, Netlify, or Vercel.
- Keep the assets folder alongside index.html so the profile photo and resume links work.

Edit index.html to update text, links, skills, projects, or education.
The page is responsive and uses a light theme. Google Fonts are loaded online; system sans-serif fonts are used as fallback.
